## The joke

> HR sent me a birthday card addressed to my predecessor. He left in 2019.

One line, 72 characters. It turns on a real office detail — an HR
birthday card — and lands the laugh in the last few words.

## How it works

`main.ts` writes the joke byte-exact to `/output/entry.txt`, after checking
it is a single line of 1–199 characters with no leading or trailing
whitespace, then reads the file back to confirm it matches byte for byte.

```sh
node main.ts
```
